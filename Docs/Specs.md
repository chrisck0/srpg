# 기능 명세

## 1. 게임 개요
- 그리드 턴제 맵 위에서 유닛을 움직여 싸우는 턴제 전략 게임 SRPG
- 레퍼런스 : 슈퍼로봇대전 30

## 2. 데이터 파싱
- 전부 CSV 파싱하여 Scriptable Object에 저장
- 외부 데이터 시트를 로드 및 로컬 CSV 파일 보관하여 로드 가능

### 2-1. 아군 유닛
- 이름, HP, EN, 이동력, 무기 목록, 명중, 회피

### 2-2. 적군 유닛
- 이름, 공격력, 최소/최대 사거리, 범위 모양, EN 소모량

### 2-3. 스테이지
- 지형 종류
- 유닛의 초기 위치

## 3. 페이즈 전환
- 아군 페이즈, 적군 페이즈 번갈아 전환
- 유닛이 전부 행동하면 자동으로 페이즈로 전환
- 턴 종료 버튼으로 페이즈 넘기기 가능
- 아군 페이즈 시작 시 EN 5 증가
- 상태 패턴으로 아군, 적 페이즈 구현

## 4. 아군 유닛
- 플레이어 페이즈에서 이동, 공격, 대기 기능
- 상태 패턴으로 조작 단계 구현(유닛 선택, 이동, 커맨드, 대상 선택)
- 아군 유닛 클릭 -> 이동 범위 표시 -> 이동할 칸 클릭 -> 경로를 따라 칸 단위 이동 -> 커맨드 메뉴 (공격 / 대기)... (나중에 사진 첨부)

## 5. 적군 유닛
- 적 AI로 자동 행동

## 6. 이동 범위
- 유닛의 이동력 안에서 갈 수 있는 칸 모두 표시
- 지형 종류마다 다른 이동 비용
- 적 유닛이 있는 칸은 지나갈 수 없다
- 아군이 있는 칸은 지나갈 수 있지만 멈출 수 없다
- 목적지 고르면 실제 경로 따라 한 칸씩 이동
- BFS, 다익스트라 사용
- 경로 탐색 시 해당 칸이 어디 칸에서 왔는지를 기록, 목적지에서 출발점까지 거꾸로 경로 생성

## 7. 무기와 공격 범위
- 유닛당 무기 2종 이상 (범위 무기 1종 이상 포함)
- 단일 무기: 최소~최대 사거리 안 적 하나 선택 (근거리: 1~1, 원거리: 2~4)
- 범위 무기: 정해진 모양 안 모든 대상 피해
- EN을 소모하여 무기 사용

## 8. 전투 계산
- 명중 여부 판정 (아군 유닛의 명중, 적군 유닛의 회피) 계산식
- 공격 전 예상 명중률, 예상 데미지 보여주는 창 띄운다
- 반격 (공격받은 유닛이 살아 있고, 공격자가 무기 사거리 안에 있으면 반격)
- 난수 계산

## 9. 적 AI
- 적 페이즈에서 한 기씩 행동
- 아군과 똑같은 이동 범위, 공격 범위 규칙을 따른다
- 행동 유형 (공격형, 대기형, 고정형)
- 공격형 - 갈 수 있는 칸 중에서 가장 좋은 공격을 할 수 있는 칸으로 가서 공격, 공격할 수 없으면 가장 가까운 아군에게 다가간다
- 대기형 - 아군이 일정 거리 안에 들어오기 전까지 움직이지 않는다
- 고정형 (보스 등) - 이동하지 않고 사거리 안에 들어온 아군만 공격한다

## 10. 승리와 패배 조건
- 승리: 적 전멸 / 보스 격파
- 패배: 아군 전멸 또는 주인공 유닛 격파
- 턴 수 제한(선택)

## 11. 인게임 UI
- 현재 턴 수와 페이즈 표시. 페이즈가 바뀔 때 화면 가운데 크기 띄운다
- 칸에 마우스 올리면 칸 지형, 서 있는 유닛 이름, HP, EN을 보여주는 정보 창
- 커맨드 메뉴, 무기 선택 목록(사거리, 공격력, EN 소모 표시), 전투 예측 창
- 턴 종료 버튼, 일시정지(ESC) 메뉴: 재개 / 메인 화면
- 적 유닛 클릭하면 그 적 이동 범위와 공격 범위를 보여줌

## 12. 결과 화면
- 클리어 / 실패 표시
- 걸린 턴 수, 격파 수, 잃은 아군 수
- 다음 스테이지, 재도전 / 메인 화면 버튼

## 13. 옵션
- BGM / SFX 볼륨 조절

## 14. 추가 구현
### 턴 되돌리기
- 전 아군 페이즈 턴으로 되돌리기 (횟수 제한)
- 되돌렸을 때 플레이어가 동일하게 행동하면 명중 결과가 같게 나오도록 난수 고정

### 전체 피격 범위 표시
- 아군 페이즈에서 맵 좌표에 피격 범위 표시

### 아군 유닛 공격 범위 표시
- 아군 유닛 공격 커맨드 눌렀을 때 무기에 따라 공격 가능한 범위를 이동 범위와 함께 표시
- 공격 버튼 누르고 무기 선택했을 때 이동한 다음에 추가 커맨드 메뉴 또는 바로 방향 선택해서 공격

### AUTO
- 아군 자동 진행
